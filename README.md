# 삼국지14 CE 계절 맵

삼국지14 CE 한국어판(2026-11-05 공식 업데이트판) 전용 계절 맵입니다.
땅·산·강·나무가 계절 따라 바뀌고, 날씨와 재해가 실제로 전쟁에 영향을 줍니다. 순정 칸 판정·길·거점은 그대로 두고 그림과 규칙만 더합니다.

## 처음 받는 분 (한 번만)
1. 위 초록색 **Code** 버튼 → **Download ZIP** 을 눌러 받습니다(약 100MB).
2. 받은 ZIP 을 아무 새 폴더에 풉니다. (Program Files·OneDrive 폴더는 피해 주세요)
3. 풀린 폴더의 **처음_설치.cmd** 를 더블클릭합니다.
   - 알아서 `계절 맵` 폴더를 만들고 설치기를 엽니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
4. 게임을 끈 상태에서 설치기의 **[설치 / 다시 맞추기]** 를 누르면 끝입니다.

## 그다음부터
설치기(`계절 맵` 폴더의 **설치.cmd**)를 켜면 새 판이 있는지 알려 줍니다. **[업데이트]** 버튼만 누르면 새 판을 그 폴더에 바로 덮어쓰고 적용합니다(새 폴더를 만들지 않음).
여기서 따로 받을 것은 없습니다. 예전 판으로 돌아가려면 **[버전 되돌리기]** 를 누르세요.

## 바뀐 내용
설치기의 **'업데이트' 탭**에서 판마다 바뀐 내용을 볼 수 있습니다.
