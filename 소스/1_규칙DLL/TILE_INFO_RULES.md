# 타일 정보창용 규칙 정리 (v26, v2 기후 데이터 기준) — 2026-10-19

출처: rules/season_rules_v26.c, rules/engine_v26.inc (v2 = SeasonRules_v26.dat, 실제 쓰는 경로. v1 이벤트 경로는 옛 데이터용이라 무시)
규칙 상태는 게임 하루마다(턴 진행 중) 바뀜. 턴이 멈춰 있으면 안 바뀜 → 정보창도 그대로.

## 이속 (spd_cell, 하루마다 표로 계산 spd_fac)
- 홍수 flooded 1/2/3(홍수/큰 홍수/대홍수): ×0.60/0.45/0.35 — 이때 눈·얼음은 무시(else-if)
- 언 강 mine==1: ×0.50, 녹기 전 턴 ×0.30
- 쌓인 눈 cSnow 1/2(얕은/깊은): ×0.85/0.70. 내리는 눈은 쌓인 눈 단계를 올림: 눈→얕은, 눈보라→깊은, 진눈깨비 없음
- 화재 burning: 최대 ×0.50
- 지진 quaked 1/2/3(지진/강한/대지진): 최대 ×0.80/0.70/0.60, 2/3/4턴 유지
- 진흙 mud(물 빠진 뒤 2턴): 최대 ×0.90
- 비·눈 단계 2/3(비·눈 / 폭우·눈보라): 곱하기 ×0.95/0.90, 숲·산(vterr 5,6,8~11) ×0.90/0.80
- 산사태: 땅이 통행 불가 지형으로 바뀜(3턴). 이미 있던 부대는 안 막힘
## 매 턴 계속되는 피해 (진행형)
- 비·눈 단계 2: 사기 -1/턴, 단계 3: 사기 -3/턴 (최저 10). 눈에도 똑같이 적용 (rain[] 단계 공용)
- 화재(v2 fire_hurt, 매 턴): 그 칸 부대 70% 확률로 병력%·사기 각각 무작위
  산불(<10칸) 5~10, 큰 산불(10~29) 10~15, 대산불(30+) 15~20
## 화계 성공률 (FireRateHook)
- 단계 1(가랑비·진눈깨비) ×0.8, 2(비·눈) ×0.5, 3(폭우·눈보라) 0 = 불가
## 순간 한 번만 (진행형 아님 → 정보창에 안 씀)
- 홍수: 물이 불어 새로 잠길 때 그 칸 부대 (L1 10%, L2 30~60%, L3 70%) → 병력50/사기40 또는 30/25
- 지진: 일어날 때 범위 안 부대 확률로 50/40 또는 30/25
- 산사태: 일어날 때 그 칸 부대 50%로 20/20
- 언 강 녹을 때 위에 있던 부대 25%로 15/15 (해마다 부대당 1번)
## 부대에 효과 없는 땅 상태
- 가뭄 균열 crack: 효과 없음(산불 잘 남 ×1.5)
- 불탄 자리 ash: 효과 없음(새 불 안 남, 산사태 ×3)
## 정보창 이름
- 땅: 얕은 눈 / 깊은 눈 / 언 강 / 진흙 / 가뭄 균열 (+ 불탄 자리? 사용자 확인 필요)
- 날씨: 가랑비·비·폭우 / 진눈깨비·눈·눈보라
- 재해: 산불·큰 산불·대산불 / 홍수·큰 홍수·대홍수 / 지진·강한 지진·대지진 / 산사태
