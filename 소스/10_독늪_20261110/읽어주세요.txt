독늪 다시 보이게 (v26k43, 2026-11-10)

문제: 운남·남중 둘레의 독늪(지형 번호 7)은 순정에서 보라색 바닥으로 그려지는데, 계절 맵이 땅 재질만 보고 풀·흙 사진과 계절 색을
      덮어 그려서 보라색이 사라졌음 (제보: "4계절 모드를 깔면 독천이 보이지 않는다").

1) mk_swamp_mask.py : 독늪 바닥 자리를 season_forest.dds 의 초록(g) 칸에 넣음 (그 칸은 원래 비어 있었음 - 새 파일 없음).
                      자리는 게임 지형 자료(FieldEditor4.rdb.bin14 tex 구역, G1T 1번 텍스처 2049x2049 RGBA8)의 파랑 칸 = 바닥 종류에서
                      8·16번 (그 점의 98% 가 지형 번호 7 칸 위). 1024 로 줄이고 3x3 로 살짝 흐리게.
                      python3 mk_swamp_mask.py tex_bin_raw.bin season_forest.dds
2) 셰이더 4개 (3_셰이더: SeasonTerrainNear/Far.hlsl, d3e1f71e / 9addb6cb -ps_replace.txt) 의 season() 안,
   날씨·재해 그림 바로 앞에 같은 6줄을 넣음: 독늪 자리에서는 계절 바닥(A, M)을 순정 쪽(A=0, M=1)으로 되돌림.
   그 뒤의 비 구름 그림자·젖은 땅·홍수·산불 등은 그대로 위에 그려짐. 독늪이 아닌 곳은 값이 정확히 0 이라 계산 자체를 건너뜀.
3) .bin 4개는 SeasonShaderPrep.exe(게임 폴더의 d3dcompiler_46) 를 wine 으로 돌려 만듦. 같은 방법으로 바뀌지 않은 셰이더 16개를
   다시 만들어 보니 배포본과 한 바이트도 다르지 않았음 (만드는 길이 같다는 확인).
4) 규칙 DLL 은 판 표시 글자만 바꿈 (메시지 창 "계절 맵 v26k43", 알림 코드 SM43). 코드는 v26k42 그대로.

v26k44 (같은 날, 정식판): 독늪은 순정 그대로
5) 셰이더 4개의 같은 6줄을 season() 맨 끝(날씨·재해 그림 뒤)으로 옮김: 독늪 자리에서는 비 구름 그림자·젖은 땅·홍수 물·산불 자국까지
   모두 걷어 내서 땅은 완전히 순정. 공중의 비·눈·구름(SeasonRain)과 날씨 규칙은 그대로. 산 높이는 원래부터 이 자리 순정과 같음.
6) 규칙 DLL 판 표시 글자: "계절 맵 v26k44", 알림 코드 SM44 (코드는 v26k42 그대로).

v26k45 (2026-11-11, 정식판): 세력색 지도 정리
7) 세력 색 셰이더(48bed74946919969-ps_replace.txt) 끝의 색 고르기:
   - 경계 줄(r13.z): 예전 그대로 - 가파른 벽 위의 거의 검은 줄만 안 그림
   - 주인 없는 땅의 거의 검은 띠/칠(r1.x, cb0[269]): 이제 경사와 상관없이 안 그림 (멀리 당기면 칸 전체를 덮던 것 - 전에는 가파른 곳만 빠져서 들쭉날쭉)
   - 세력색 칠(r12): 독늪 자리(season_forest.dds 초록, 세계 좌표/200 - 0.5 = 1024 지도의 칸)에서 진하기 반으로 → 보라색이 비쳐 보임
   d3dx.ini 에 [ShaderOverrideSAN14Territory] 를 더해 t119(독늪 지도)를 이 셰이더에 묶음.
8) 독늪 지도를 높이 지도 해상도에서 먼저 부드럽게(시그마 3칸) 흐린 뒤 1024 로 줄임 → 가장자리 계단 모양 없음 (땅 셰이더는 그대로).
9) 규칙 DLL 판 표시 글자: "계절 맵 v26k45", 알림 코드 SM45.
